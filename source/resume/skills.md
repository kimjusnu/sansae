# 보유 기술 · 강점

## 기술 스택
- **Frontend**: React, Next.js (App Router, RSC), TypeScript, Tailwind CSS
- **AI/ML**: LLM 통합, SAM2 모델, FastAPI
- **DevOps**: GitHub Actions, Docker, PM2, CI/CD
- **Data/분석**: GA4(Google Analytics 4, 인증 보유), Microsoft Clarity 히트맵
- **기타**: RBAC(역할기반 접근제어), i18n 라우팅, Zustand, Tiptap, MUI, Storybook

## 강점 (자기소개서·포트폴리오 활용)
- 기획 → 디자인 → 구현 → 배포 → 운영까지 **제품 전 과정 오너십**
- 프론트/백엔드/인프라를 아우르는 풀스택 실행력
- 현장 리서치 기반 문제 정의 (예: 농가 직접 방문)
- 설득력 있는 커뮤니케이션, 논리적 사고
