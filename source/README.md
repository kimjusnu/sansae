# source/ — 원자료 (Source of Truth)

여기 있는 파일이 **모든 사실의 단일 출처**다. 포트폴리오 사이트와 자기소개서는
전부 이 폴더의 내용을 근거로 만들어진다. **이 폴더는 가공·수정하지 않는다.**

- `resume/`   — 이력·경력 원본 (경력기술서, 이력서 파일 등)
- `projects/` — 프로젝트별 상세 (프로젝트당 파일 1개 권장)
- `awards/`   — 수상·공모전 실적 (증빙 포함)
- `etc/`      — 자격증·어학·링크·기타

형식은 자유(마크다운/PDF/이미지/텍스트)지만, 가능하면 마크다운이 다루기 좋다.
