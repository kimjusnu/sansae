## 2. 요건 vs 내 스펙 — 우대사항이 곧 내 이력서다

| 공고 요구 | 내 실증 | 매칭 |
|-----------|---------|------|
| **AI(Chatbot, LLM, RAG, Agent) 서비스 개발 경험** (우대) | LLM 통합 실무(오류율 10→3%), 포트폴리오 챗봇(Workers AI + persona grounding), 부패도 검증 AI UI | 🟢🟢 정면 일치 |
| **공통 UI 컴포넌트·디자인 시스템 구축·운영** (주요업무) | **Componique — 30+ 컴포넌트, npm 주간 127K, 디자인 토큰 표준화** | 🟢🟢 직결 |
| **노드 기반 에디터 개발** (주요업무·우대) | StartupQT Tiptap 모듈형 에디터 (노드 에디터는 아니나 에디터 아키텍처·상태 관리 경험) | 🟡 유사 경험 — 거짓 없이 "에디터 개발 경험 + React Flow 학습 의지"로 |
| React 기반 SPA·유지보수 | React/Next.js 실무 전 기간 | 🟢 |
| Figma 시안 → 퍼블리싱·인터랙션 | 디자이너 협업(GitHub Profile Viewer), 실무 퍼블리싱 | 🟢 |
| HTML/CSS/TS 퍼블리싱·UI | 실무 + 반응형·접근성(시니어 UX 가이드 작성) | 🟢 |
| REST API 연동·Git | FastAPI 연동 실무, GitHub Actions CI/CD | 🟢 |
| CS 학사 | 한국공학대 컴퓨터공학부 | 🟢 |
| Tailwind (우대) | 실무 사용 (Tailwind v4 트러블슈팅 경험까지) | 🟢 |

**핵심 서사**: "AI 제품을 만드는 FE"를 이미 하고 있는 지원자.
- 솔트룩스 Product Center가 하는 일(AI 기술의 제품화) = AimBe Lab에서 한 일(부패도 AI·LLM을 실사용 SaaS로)
- 여기에 디자인 시스템(Componique)·에디터(StartupQT)까지 얹으면 주요업무 8줄 중 7줄이 커버됨
