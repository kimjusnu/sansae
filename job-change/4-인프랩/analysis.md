## 2. 요건 vs 내 스펙 (경쟁자 키워드 기반 추정 — JD 원문 확인 후 갱신)

| 인프랩이 보는 것 (키워드) | 내 실증 | 매칭 |
|---------------------------|---------|------|
| **Design System 구축** | Componique 30+ 컴포넌트·npm 127K·디자인 토큰 | 🟢🟢 |
| **AI 활용 능력** | LLM 통합 실무, SAM2 도입 제안, Claude Code 등 AI 도구 워크플로우 | 🟢🟢 |
| 피그마·프로토타이핑 | 디자이너 협업 + Figma 기반 구현 실무 | 🟢 |
| 데이터 기반 의사결정 | GA4·Clarity 계측, A/B 테스트 설계 경험 | 🟢 |
| 자기주도 학습 | RSC 도입, 자체 i18n, SAM2 스스로 조사·제안 | 🟢 |
| (추정) Next.js/React 스택 | 인프런은 Next.js 기반으로 알려짐 — RSC 실무 직결 | 🟢 |

**핵심 서사 각도**: "개발자 교육 플랫폼"에 맞는 지원자상 = 스스로 학습해서 제품을 바꾼 사람.
- SAM2 스토리(답답해서 직접 조사→제안→90→97%)가 인프런의 "자기주도 학습" 가치와 정확히 공명
- 오픈소스 Componique(다른 개발자들이 쓰는 도구를 만든 경험)는 "개발자를 위한 제품" 회사에 특히 매력적
- 인프런 수강 이력이 있다면 지원동기에 반드시 언급 (본인 확인 필요)
