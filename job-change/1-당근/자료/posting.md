## 팀 소개
당근 커머스팀은 지역 기반 로컬 커머스를 재정의하는 조직. 2,000만 당근 사용자가 익숙한 환경에서 중고거래·커뮤니티·동네지도 등과 연결된 커머스 플랫폼 구축 중. 공동구매, 로컬 MD 등 기존 이커머스에 없는 가치 창출 목표. 초기 스타트업처럼 전 구성원이 PM이자 리서처로서 고객 문제에 집착, 빠른 실행과 실패로부터의 학습 중시.

## 주요 업무
- **매력적인 커머스 UX 개발**: 상품 탐색→구매 완료까지 직관적 인터페이스 설계·구현, 웹뷰·웹사이트 간 일관된 경험, 이벤트/기획전 페이지 빠른 배포
- **실험과 학습**: 실험적 기능 빠른 구현·테스트, 일상적 A/B 테스트, 데이터 기반 지속 개선
- **판매자 관리 도구 개발**: 상품 등록, 주문/재고 관리, 정산, 판매 성과 대시보드
- **AI 활용 개발 고도화**: Claude Code, Cursor 등으로 UI 컴포넌트 빠른 구현, 프로토타입, 반복 작업 자동화

## 자격요건
- 프론트엔드 기반 서비스/프로젝트 **주도적 개발·운영 경험** (경력 년수 명시 없음)
- 고객 문제 해결에 대한 집착, 오너십
- 새로운 기술 스택 빠른 적응, 빠른 실행 vs 확장성 균형
- 다양한 직군과 열린 협업, 실패로부터 학습
- 엔지니어링 관점의 자율적 판단·실행
- **AI 도구(Claude Code, Cursor 등) 적극 활용**

## 우대사항
- TypeScript, React

- 복잡한 상태 관리 (Recoil, Zustand 등)

- 웹브라우저·인앱 웹뷰 실행 환경/정책 이해
