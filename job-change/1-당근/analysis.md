# 당근 FE 커머스 — 지원 분석

## 1. 제출 서류
| 서류 | 필요 여부 | 비고 |
|------|-----------|------|
| 이력서/경력기술서 | ✅ 필수 | 자유 양식(온라인 지원서 + 파일 첨부). `제출물/` 초안 참고 |
| 자기소개서 | ➖ 별도 문항 없음 | 이력서 내 간단한 소개·지원동기 포함 권장 |
| 포트폴리오 | 🔶 강력 권장 | 라이브 링크(사이트·GitHub·npm)가 곧 포트폴리오 |
| 증빙 | ❌ 서류 단계 불필요 | 최종 단계 레퍼런스 체크 있음 |

## 2. 요건 vs 내 스펙 매칭표

| 요구사항 | 내 근거 (source/) | 매칭 |
|----------|-------------------|------|
| FE 서비스 **주도적 개발·운영** | AimBe Lab: My Feed 기획→개발→배포→운영 전 과정. B2B 사이트 재구축 단독 주도 | 🟢 강함 |
| 고객 문제 집착 · 오너십 | **농가 직접 방문** 리서치 → 문제 정의 → GA4 최적화로 주간 방문 2~3→4회 | 🟢 강함 (팀 문화 "PM이자 리서처"와 정확히 일치) |
| **AI 도구 적극 활용** | LLM 통합 실무(분류 오류율 10%→3%), SAM2, FastAPI. AI 도구 기반 개발 워크플로우 | 🟢 강함 (JD의 Claude Code/Cursor 항목 직결) |
| TypeScript·React (우대) | 전 프로젝트 TS/React/Next.js | 🟢 |
| 상태 관리 Zustand (우대) | StartupQT에서 Zustand 실무 | 🟢 |
| 이커머스 도메인 (우대) | My Feed = 농가 **주문 시스템** (주문·정산 흐름 경험) | 🟡 부분 — "커머스"로 포장 가능하나 과장 금지 |
| GraphQL/Relay (우대) | 근거 없음 | 🔴 공백 — 지원서에 "학습 중" 등 거짓 작성 금지. 언급 안 하거나 빠른 적응 사례로 대체 |
| A/B 테스트·데이터 개선 | GA4 인증 + GA4/Clarity 기반 개선 실무 | 🟢 |
| 인앱 웹뷰 (우대) | 명시 근거 없음 (Eat Fit PWA는 유사 경험) | 🟡 |

**종합**: 자격요건 6개 전부 실증 가능. 우대 5개 중 3개 충족. 총 매칭 ~80%.
**최대 무기**: ①JD가 요구하는 "AI 도구로 생산성" = 실무로 증명 가능한 희소 스펙 ②"PM이자 리서처" 문화 = 농가 방문 리서치 스토리 ③숫자 있는 성과(10%→3%, 2~3→4회, 127K).
