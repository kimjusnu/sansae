# Junsu Kim — Portfolio

프론트엔드 · AI 엔지니어 **김준수**의 인터랙티브 포트폴리오.

- **콘셉트**: `DIVE` — 스크롤로 데이터 심해를 내려가는 인터랙티브 경험
- **기술**: 순수 HTML / CSS / JavaScript (라이브러리 0, Canvas 손코딩)
- **특징**: 인트로 게이트 · 수심 게이지 · 소나 커서 · 마스코트 MOTI 🪼 · 라이트모션 대응

## 로컬 실행
`portfolio/index.html`을 브라우저로 열면 됩니다. (빌드 불필요)

## 배포 (GitHub Pages)
`main` 브랜치에 push하면 `.github/workflows/pages.yml`이 `portfolio/`를 자동 배포합니다.
GitHub 저장소 → **Settings → Pages → Source: GitHub Actions** 설정 필요.
